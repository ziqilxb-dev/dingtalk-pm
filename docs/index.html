执行方式

把依据带进下一步。

01 / 按需读取

你指定范围，它再检查

根据任务读取指定聊天、会议或文档。两平台的能力和权限分别核对，分页和正文缺口明确标注。

02 / 结论有据

一句“可以”，有明确指向

区分已确认决定、建议与冲突。关键结论保留资料来源，只提取真实承诺，不把未回复当同意，不补造期限。

03 / 完成交付

整理之后，继续做产品工作

围绕需求、评审和变更核对推进 PRD、原型、流程、验收与数据分析。按授权修改目标文档，并保留原规则与读回核验结果。

运行条件

需要可执行本地命令和访问文件的 AI 工具、Python 3.9+。仅使用产品流程不要求登录办公平台；接入时使用自己的账号，企微标准安装另需 Node.js 18+。客户端补读取决于宿主与系统权限。

验证范围与使用边界

钉钉聊天与一条自建听记已在 macOS 实测；听记转写共 58 段、两页一致。企微 CLI 安装和启动已验证，真实业务读取未验证。其他系统完整真机验证待完成。演示案例均为虚构，不代表实际执行结果。
