# 钉钉接入

钉钉环境检查用 `python scripts/doctor.py --provider dingtalk`；不带参数的doctor只检查包完整性。

DWS安装与自检见 [部署](compatibility.md)，聊天用collect.py，听记见 [听记](minutes.md)，文档见 [文档读取与写回](pm-handoff.md)。以下相对引用按本目录解析。

## 聊天读取与补齐

1. 从本轮上下文确定会话、时间或主题、期望输出。截图人名要与会话列表核对；有歧义才问。未给时间先读最近30条，说明实际日期，并按话题补上下文，不强迫用户先填写参数。不扩展至整个组织或该人的全部群聊；私聊读取双方消息。
2. 首次使用读 [CLI与完整性](cli.md)，运行 `scripts/collect.py` 单次读取，生成保留原始记录的证据包。原始数据放项目 `.work-assistant/runs/dingtalk/`，不放skill目录。
3. 分开检查分页、正文、引用和附件。退出码0或complete=true不能证明正文完整，空正文也需检查。
4. 缺失影响主题判断时，用 [客户端补读](client.md) 按需读取已登录客户端。提前简短告知必要的窗口切换，已授权读取无需重复确认；优先辅助功能文字，必要时才截图。无法定位或缺权限时，完成不依赖缺口的整理，再说明具体需用户操作什么。
